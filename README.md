# Cnamio SDKs

Server SDKs for [Cnamio](https://cnamio.com/?utm_source=sdk-repo): let your users connect their own custom domain to your app (DNS provider detection, automatic or guided records, propagation checks, signed webhooks).

- `npm/`: the `cnamio` package for Node.js 18+ (one file, no dependencies, typed).
- `python/`: the `cnamio` package for Python 3.9+ (standard library only).

Docs: https://cnamio.com/docs · For coding agents: https://cnamio.com/agent-onboarding/SKILL.md · Agent kit: https://github.com/cnamio/agent-kit

These files are published from Cnamio's service, which serves the same SDK at https://cnamio.com/sdk/. Issues and questions: contato@cnamio.com. MIT license.
